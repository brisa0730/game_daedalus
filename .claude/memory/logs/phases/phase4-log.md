Every `TileCollision` query tests Solid boxes (Hazard boxes in `CoreTouchesHazard`), nearest hit wins. **Decision:** box overlap is strict *within the contact epsilon* (`SpansOverlap`), matching how cells are covered, so a pushed player flush against a box face never reads as inside it through float rounding. 5. **Riding.** `BoxPush.ApplyPush` (one push effect; rope lockout +1 only before the player's step, F4). Riders by old top; carriers by highest new top, then |dx|, then dx. 6. **Push, crush, nudge.** `BoxPush.Resolve` (leading face, targets combined by value, opposite pushes squeeze) and `TryNudge` (least shift ≤ 0.25 at right angles that clears every pusher; ties up, left, right, down).

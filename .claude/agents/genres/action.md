# Action

## Core Fun Elements
- Impact sensation: Weighty, responsive feedback on every hit
- Control responsiveness: Instant, accurate input response
- Skill ceiling: Visible improvement with mastery

## Gold Standard
- DMC5: Deep combat system with style rankings driving creative expression
- God of War: Weighty, visceral combat with seamless camera work
- Monster Hunter: Weapon diversity with preparation-as-gameplay loop

## Player Expectations
- Instant accurate input response
- Weighty character motions
- Distinct weapon/skill handling
- Readable enemy patterns
- Clear skill-based improvement
- Satisfying boss encounters
- Stable camera/lock-on

## Player Demands
- Minimal input latency
- Impact feedback (visual/audio/haptic)
- Clear evasion/defense mechanics
- Readable but challenging enemy AI

## Delight Points
- Post-mastery perspective shift ("the whole game looks different now")
- Unexpected combo discoveries
- Boss pattern mastery leading to no-hit clears
- Creative play enabled by deep systems

## Genre Landmines
- Input lag / input eating
- Unfair hit detection
- Camera obscuring enemies
- Button-mashing being the optimal strategy
- Overuse of QTE cutscenes

## Anti-patterns
- Flashy-but-shallow action (looks cool, no depth)
- Inconsistent evasion invulnerability frames
- Unreadable random enemy behavior
- Unbalanced weapon/skill options
- Damage-sponge boss padding

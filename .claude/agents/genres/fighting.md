# Fighting

## Core Fun Elements
- Frame reading: Reacting to and predicting opponent actions
- Combo creativity: Expressing mastery through combo routes
- Competitive tension: Every match is a mental chess game

## Gold Standard
- SF6: Modern accessibility without sacrificing depth
- Guilty Gear Strive: Style-driven character design with deep systems
- Tekken series: Legacy of layered depth rewarding long-term investment

## Player Expectations
- Distinct character individuality
- Input precision (commands execute as intended)
- Consistent frame data
- Rollback netcode stability
- Comprehensive tutorials
- Clear learning progression path

## Player Demands
- Input accuracy (no dropped inputs)
- Stable online netcode
- Continuous balance patches
- Accessible frame data in training mode

## Delight Points
- Last-second HP comeback reversals
- Landing a mastered combo in a real match
- Perfect reads on opponent habits
- Full-set competition drama

## Genre Landmines
- Poor netcode (delay-based online)
- Extreme entry barriers (no onboarding)
- Ignored balance (one character dominates)
- Weak single-player content
- Complex command inputs as artificial barriers

## Anti-patterns
- "Combo movie" games (long combos, no neutral game)
- No meaningful defense options
- Pay-to-win character sales
- Ineffective ranking systems
- One-sided fun design (winner has fun, loser doesn't)

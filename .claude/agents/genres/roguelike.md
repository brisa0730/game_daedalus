# Roguelike

## Core Fun Elements
- Run variety: Every run feels different
- Build discovery: Finding unexpected item/skill synergies
- "One more run" addiction: Quick restarts feeding compulsive loop

## Gold Standard
- Hades: Narrative that progresses through death — story and roguelike loop unified
- Slay the Spire: Perfect information + deck-building depth — every card matters
- The Binding of Isaac: Item synergy explosion creating emergent chaos

## Player Expectations
- Diverse runs with different builds each time
- Build combinations and synergies
- Fast restarts after death
- Meaningful risk-reward choices
- Meta progression via permanent unlocks
- Procedural generation variety
- Appropriate session length (30min-1hr)

## Player Demands
- Sufficient variety for new builds each run
- Fair death-as-learning design
- Occasional OP build satisfaction (power fantasy moments)
- Balanced meta progression (doesn't trivialize the game)

## Delight Points
- Unexpected item synergies creating something broken
- Unlikely comeback victories
- First-time combo discoveries
- Overcoming runs that started with terrible RNG

## Genre Landmines
- Build diversity shortage
- Early-game RNG fatality (dead on arrival)
- Overwhelming permanent upgrades
- Excessive run length
- Repetitive procedural generation

## Anti-patterns
- "Grinding roguelikes" (play more = stronger, not better)
- Synergy-less linear item progression
- Identical boss patterns every run
- Information opacity (no way to know what items do)
- Linear run structure (no meaningful routing choices)

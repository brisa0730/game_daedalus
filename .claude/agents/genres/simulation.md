# Simulation

## Core Fun Elements
- System comprehension: Understanding how everything connects
- Optimization satisfaction: Making things run more efficiently
- Growing world: Watching your creation evolve and expand

## Gold Standard
- Factorio: Perfect system-interaction depth — the factory must grow
- RimWorld: Emergent storytelling through simulation systems
- Two Point Hospital: Accessible simulation with humor and depth

## Player Expectations
- System-interaction depth
- Efficiency-improvement feedback loops
- Problem-solving freedom (multiple valid approaches)
- Visual facility/world growth
- Game speed control
- Statistics/graphs for data lovers
- Crisis events creating tension

## Player Demands
- Transparent and predictable systems (cause→effect traceable)
- Multiple valid strategies
- Scalable expansion
- Large-scale management UI
- Stable framerate at scale

## Delight Points
- Perfect system synchronization moment
- Systematically resolving a crisis
- Personal unique strategy actually working
- Realizing how far you've grown from the beginning

## Genre Landmines
- Opaque system mechanics (can't understand cause→effect)
- Single optimal solution for everything
- Micromanagement hell (too many small tasks)
- Irreversible failure states
- Late-game frame drops

## Anti-patterns
- Surface-level simulation (looks complex, plays shallow)
- Optimization-free linear growth
- RNG invalidating strategy
- No tutorial, steep learning cliff
- Late-game content drought

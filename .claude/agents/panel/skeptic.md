# Skeptic

**Lens:** Assumptions, exploits, degenerate strategies, and what players will actually do.

**Core question:** "What happens when a player tries to break this?"

## Evaluation Criteria
- **Assumptions** — What's being taken for granted about player behavior? Has it been tested?
- **Degenerate strategies** — Is there an optimal path that bypasses the intended experience?
- **Edge cases** — What happens at 0 resources? Max level? 1000 hours? Two players cooperating to exploit?
- **Second-order effects** — What does this decision force downstream? What options does it close?
- **Reversibility** — If this design is wrong, how hard is it to change post-launch?
- **Player trust** — Does this feel fair, or will players suspect the game is cheating?

## When to Invoke
- Before committing to a core mechanic or system
- When a design sounds too clean or elegant on paper
- When the team is converging on an idea without pushback
- Evaluating multiplayer balance or competitive integrity

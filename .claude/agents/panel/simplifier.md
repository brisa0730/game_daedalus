# Simplifier

**Lens:** Scope control, minimum viable fun, and what to cut.

**Core question:** "What's the smallest version of this game that's still worth playing?"

## Evaluation Criteria
- **Necessity** — Does every system earn its place? What happens if you remove it?
- **Feature weight** — Is this feature's fun proportional to its development cost?
- **Cognitive load** — Can the player hold the rules in their head without a tutorial?
- **Scope creep** — Are we solving the core design or chasing "wouldn't it be cool if" ideas?
- **Vertical slice** — Could we ship one level of this and know if it's fun?
- **Kill candidates** — What's the weakest system? Would the game be better without it?

## Common Pitfalls
- "Just one more system" mentality that delays the fun
- Tutorial complexity as a symptom of design complexity
- Features kept because they took effort to build, not because they're fun
- Designing for the 100-hour player before the 10-minute player
- Settings menus with options nobody will ever change

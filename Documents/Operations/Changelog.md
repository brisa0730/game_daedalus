## v0.03 — Unity platform (2026-10-21) · **docs only, no code**

- **Landed.** The operator moved the project from a browser tool to a **Unity 6 package** that students use inside the Unity Editor, code-free: package `com.orcapafea.daedalus`, installed from OpenUPM, minimum Unity 6000.0, developed on 6000.6.7f1 and tested on 6000.0.85f1 too. The custom pure sim carries over (its own assembly, no engine references, no Unity 2D physics for gameplay); Unity's Tilemap, sprites, URP 2D, Input System and editor replace the Canvas 2D renderer and the React editor. The browser scaffold (its plan and code) was removed from git history at the operator's request, so this v0.03 follows v0.02 directly.
- **Design.** Unity's own tools now cover painting, navigation, placement, undo and saving; `editor-core` becomes the smaller `editor-tools` (play-from-here, inspectors, presets, validation, scene autosave). The JSON project format and its migrations give way to authored data (a scene + ScriptableObject assets) that every package update must keep loading. Live tuning uses a settings asset so Play-mode changes persist. The dual-grid auto-tile layout is reopened as an Open decision, since Unity has no dual-grid tilemap; hosting is now for WebGL builds. The minimap is dropped.
- **GDD deltas.** GDD v0.02 → v0.03: [GDD.md](../GDD/GDD.md) (header, pitch, pillar 6 "Unity's tools first", core loop, open questions), [architecture.md](../GDD/architecture.md) (assemblies, time model, data flow, technology), [platforms.md](../GDD/platforms.md) (rewritten: Unity versions, distribution, storage), [systems.md](../GDD/systems.md) (Editor Tools, Tile System, Asset Import, Share), [entities.md](../GDD/entities.md) (terrains, authored data), [content.md](../GDD/content.md), [conventions.md](../GDD/conventions.md), [Glossary.md](../GDD/Glossary.md); [Roadmap.md](Roadmap.md) (§1 milestones, §2 gates, §3, §4 auto-tile layouts + hosting); CLAUDE.md (stack, architecture, conventions, testing, project config); `decisions.md`; the audit skill's clusters; `.nvmrc` removed. Commit: `v0.03: Unity platform — Unity 6 package, code-free students in the Unity Editor, OpenUPM`.
